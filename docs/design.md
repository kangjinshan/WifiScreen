# 幕夜影院 / Cinema

2026-10-08，用户从四套 imagegen 全应用方案中选择 A。

视觉：深炭黑 #101214、面板 #191C1F、暖白 #F6F2E9、辅助文字 #B5B1A9、暖金焦点 #F2BD66。原生 Android Views 保留硬件视频接收，所有主要控件可用 DPAD 操作，普通播放时隐藏控制层。

背景 `android/app/src/main/res/drawable-nodpi/cinema_background.webp` 由 Azure 0932 的 gpt-image-2（2560×1440，high）生成，再缩为 1920×1080 WebP。实际背景提示词：深色影院风电视背景，上方 70% 保持近黑留白，下方中央柔和琥珀色地平线，两侧低矮暗色沙丘，底部为控件留暗部；无文字、图标、按钮、人物或水印。界面文字、图标、焦点和布局由原生控件绘制，不把概念图整张贴成界面。

界面包括等待投屏、设备设置、名称编辑、连接帮助、恢复状态、投屏菜单、画面调整、设备诊断与详细报告。名称、实时速率、画面设置本地保存。背景、启动图标与 TV 横幅均随 APK 离线提供。

菜单返回规则：全屏投屏时打开菜单；菜单时收起；子页时返回上一层；结束投屏单独确认；首页返回退出。网络恢复后只恢复接收服务，明确提示用户从手机重新投屏。

按钮的图标在左侧独立绘制，文字在对称内边距内按整个按钮居中；使用应用自己的暖金焦点背景，关闭系统叠加的默认焦点高亮。较矮的显示区域使用紧凑首页尺寸，保持连接状态可见。
